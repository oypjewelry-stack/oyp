What photoSet does
  Admin and production manager only. The server checks the role again.
  The file is saved as <JO>-photo-<timestamp>.jpg in the JO folder
  (JobOrders.drive_folder_id, or Job Order Cards/<JO> when that cell is empty).
  JobOrders.product_photo_file_id becomes the new file id.
  updated_at and updated_by are written on that same row.
  drive_folder_id is filled in only when it was empty.
  The previous Drive file stays. No other cell is changed.
  Cached thumbnails for that JO are cleared. AuditLog gets the new file id.
