Code.gs — two short edits. Page 1 of a scan queues a JO card and a jewelry tag. The save still succeeds if the queue paste is missing.
The phone sends printJo and printTag. false skips that sticker. A missing field still queues, so an older phone gets both.
printEnqueue_ then applies the per-kind auto-print switch and skips a row that is already queued or printed for that JO and sticker.
Both FIND lines are in every Code.gs version we have (before and after the zones paste). Ctrl+H; each FIND matches once.

1. Scanner print ops, right after the token check and BEFORE the fastBump_ line, so a printer polling every 15 seconds
   does not clear the remembered pages for everyone. FIND
    if (token && req.token !== token) return json_({ ok: false, error: 'Bad token' });

REPLACE WITH
    if (token && req.token !== token) return json_({ ok: false, error: 'Bad token' });
    if (req.op === 'printQueue' || req.op === 'printMark' || req.op === 'printEnqueue' || req.op === 'printReprint') return json_(typeof printScanOp_ === 'function' ? printScanOp_(req) : { ok: false, error: 'Print queue is not pasted yet' });
