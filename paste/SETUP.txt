Done and Snooze
  Both write a Reminders row whose id starts with td- and whose status is done or snoozed, never open, so the bot does not ping it.
  Snooze (tomorrow, 3 days, 1 week) hides the line until that time, then shows it again only if the rule still matches.
  Done hides that exact line until the episode changes (the JO leaves the stage, the quote is accepted, the request is confirmed, the count of jobs in the line changes).

Role
  Admin sees every area, including peso amounts. No line shows a margin or an SRP.
  Production manager sees the same work with no money lines and no peso amounts.
  Accounting sees appointments, payments, and quotes, with no peso amounts.
  Staff see job and stage lines only, and no client names (same rule as the rest of the dashboard).

Rules the lines follow
  Stuck means 5 or more days in the current production stage. There is no standard number of days for a stage. A step target (JobStages.target_date) or a JO target (JobOrders.prod_target) is used when it is set.
  A piece is written client name, then the JO: Elena Tan · 26-287: stuck in Setting 6 days.
  There is no "in Vault over 90 days" line.
