New OAuth scope, one line. Add it only if the Apps Script project does not already have it:

    https://www.googleapis.com/auth/drive

That is the Drive scope DriveApp uses. The signed-copy upload creates a folder named Consignments in the Drive of the account the web app runs as, then a folder named with the CS number (Consignments/CS-261020-01), then the file inside it. It also reads a thumbnail of that file later. Finding a folder by name needs this scope. The narrower https://www.googleapis.com/auth/drive.file scope cannot do that. Do not add drive.readonly (it cannot create files), Gmail, UrlFetch, or any other scope.

If appsscript.json has an oauthScopes list, add the URL above to that list. When that list is present, Apps Script does not add scopes on its own. If there is no list, saving this file and attaching a signed copy asks the account that runs the web app to allow Drive. Deploy a new version after the scope is on the project. The file stays private in that account's Drive. This script never trashes or deletes a Drive file.

The rest of this file uses the spreadsheet helpers the project already has (ss_, jobRows_, jobAppend_, jobSet_, jobHeader_, jobKey_, jobStr_, jobDay_, withLock_, audit_, now_, randHex_, isExec_, stripPricing_). sessionFrom_ already runs in Auth.gs before the hook below; handleConsign_ calls it only if that hook did not pass a user. The camera and the handheld scanner stay in the browser.

One tab, named Consignment, one row per piece. setupConsignment adds that tab with a header row only when the tab is missing. A tab that already exists is not rewritten and not resized. The one exception: if the header signed_copy_url is missing, setupConsignment writes that name in the next cell of row 1. It does not change any other header and it does not change data cells. This file does not read or delete Consignees, Consignments, or ConsignmentItems. The consignee list is the distinct names on the Consignment tab. Dashboard.gs must be updated separately (see paste/Dashboard-consignment.txt). Do not paste that file over Dashboard.gs.

Headers created when the Consignment tab is missing:
ci_id, consignment_id, consignee_name, consignee_phone, jo, item_id, description, agreed_value, date_out, due_back, status, prev_location, returned_at, sold_at, paid_amount, paid_at, payment_id, notes, created_at, created_by, updated_at, updated_by, signed_copy_url

signed_copy_url is the Drive link of the signed sheet. The same link is stored on every row of that CS number. Attaching a new file updates the link and leaves the previous file in the folder.

consignment_id is the sheet number, like CS-261020-01 (CS-, the date YYMMDD, a dash, then 01, 02, … for that day). status is consigned, returned, or sold. A sheet is every row that shares a consignment_id. It is closed when every one of those rows is returned, or sold and paid. Nothing here is a separate sheet row, and nothing is deleted.

When a piece is marked sold, the consignee owes the agreed_value already on that row. paid_amount is the cumulative amount recorded against the row, paid_at is the date of the latest payment, and payment_id is the id of that latest payment. A returned piece does not need a payment. A blank agreed value is not treated as paid.

Payments.gs is not in this project copy, and paySave is not a safe function to call from here: the payments page requires a JO plus a receipt photo or a reference, and inventing a Payments row with guessed columns can break Quotes and payments. This file does not write a Payments row. Recording a payment stores paid_amount, paid_at, and payment_id on the Consignment row and audits it. A payment recorded here counts immediately (status confirmed). The audit line is the history: payer is the consignee, reference is the consignment id plus ci_id.

Agreed value, owed, paid, and balance are executive-only. The response uses the name value (copied from agreed_value) so isExec_ / stripPricing_ still cover it. owed, paid, and balance are left off the response for anyone who is not an executive. A production manager can consign, return, and sell, and does not receive the amounts or record a payment.

/**
 * Consignment: one tab named Consignment, one row per piece lent out.
 * Web actions (admin + production manager): consignList, consignSearch, consignSave, consignItem, consigneeSave, consignSigned.
 * consignPay is executive-only. It stores paid_amount, paid_at, and payment_id on the row. It does not write Payments.
 * consignSigned stores a photo or PDF of the signed sheet in Drive and writes signed_copy_url on every row of that CS number.
 * New OAuth scope, if the project does not already have it: https://www.googleapis.com/auth/drive
 * One-time: run setupConsignment. It adds the Consignment tab only when that tab is missing.
 * If the tab exists and signed_copy_url is missing, it adds that header at the far right of row 1 and nothing else.
 * Never deletes a row. Never deletes or trashes a Drive file.
 *
 * Auth.gs handleAction_, immediately after the JobSync line:
 *   if (typeof isConsignAction_ === 'function' && isConsignAction_(a)) return handleConsign_(req, s.user); // Consignment.gs

var CONSIGN_TAB = 'Consignment';
var CONSIGN_COLS = ['ci_id', 'consignment_id', 'consignee_name', 'consignee_phone', 'jo', 'item_id', 'description', 'agreed_value', 'date_out', 'due_back', 'status', 'prev_location', 'returned_at', 'sold_at', 'paid_amount', 'paid_at', 'payment_id', 'notes', 'created_at', 'created_by', 'updated_at', 'updated_by', 'signed_copy_url'];
var CONSIGN_DRIVE = 'Consignments';
var CONSIGN_ROLES = { admin: true, production_manager: true };

/** ONE-TIME. Adds the Consignment tab with its header row when that tab is missing. On an existing tab, adds signed_copy_url at the far right of row 1 when that header is missing. */
function setupConsignment() {
  var run = function () {
    var ss = ss_(), sh = ss.getSheetByName(CONSIGN_TAB), col = '';
    if (sh) {
      if (consignEnsureCopyCol_(sh)) col = 'signed_copy_url';
      return { added: [], kept: [CONSIGN_TAB], column: col, url: ss.getUrl() };
    }
    sh = ss.insertSheet(CONSIGN_TAB);
    sh.getRange(1, 1, 1, CONSIGN_COLS.length).setValues([CONSIGN_COLS]);
    sh.setFrozenRows(1);
    return { added: [CONSIGN_TAB], kept: [], column: '', url: ss.getUrl() };
  };
  var res = (typeof withLock_ === 'function') ? withLock_(run) : run();
  try { audit_('setup', 'setupConsignment', '', '', 'added ' + (res.added.join(', ') || 'none') + '; kept ' + (res.kept.join(', ') || 'none') + (res.column ? '; column ' + res.column : '')); } catch (e) {}
  Logger.log('Added: ' + (res.added.join(', ') || 'none') + '\nLeft as they were: ' + (res.kept.join(', ') || 'none') + (res.column ? '\nColumn added: ' + res.column : '') + '\n' + res.url);
  return res;
}

function isConsignAction_(a) {
  return { consignList: 1, consignSearch: 1, consignSave: 1, consignItem: 1, consigneeSave: 1, consignPay: 1, consignSigned: 1 }[String(a || '')] === 1;
}
function handleConsign_(req, user) {
  if (!user || !user.username) {
    try {
      var sess = (typeof sessionFrom_ === 'function') ? sessionFrom_(req || {}) : null;
      if (sess && sess.user) user = sess.user;
      else if (sess && sess.username) user = sess;
    } catch (e) {}
  }
  var acts = { consignList: consignList_, consignSearch: consignSearch_, consignSave: consignSave_, consignItem: consignItem_, consigneeSave: consigneeSave_, consignPay: consignPay_, consignSigned: consignSigned_ };
  if (!req || !acts[req.action]) return { ok: false, error: 'Unknown action' };
  if (!user || !CONSIGN_ROLES[user.role]) {
    try { audit_((user && user.username) || '', 'denied', req.action, req.device_id, 'role ' + ((user && user.role) || '')); } catch (e2) {}
    return { ok: false, error: 'Not allowed', code: 'FORBIDDEN' };
  }
  if (!isExec_(user) && consignSentValue_(req)) {
    try { audit_(user.username, 'denied', req.action, req.device_id, 'agreed value from role ' + user.role); } catch (e3) {}
    return { ok: false, error: 'Agreed value is for executives only', code: 'FORBIDDEN' };
  }
  if (req.action === 'consignPay' && !isExec_(user)) {
    try { audit_(user.username, 'denied', req.action, req.device_id, 'payment from role ' + user.role); } catch (e4) {}
    return { ok: false, error: 'Recording a payment is for executives only', code: 'FORBIDDEN' };
  }
  var write = req.action === 'consignSave' || req.action === 'consignItem' || req.action === 'consigneeSave' || req.action === 'consignPay' || req.action === 'consignSigned';
  var res;
  try { res = write ? withLock_(function () { return acts[req.action](req, user); }) : acts[req.action](req, user); }
  catch (err) { res = { ok: false, error: String(err && err.message || err).slice(0, 300) }; }
  return (typeof stripPricing_ === 'function') ? stripPricing_(res, user) : res;
}
function consignSentValue_(req) {
  var items = req.items || [], i, v;
  for (i = 0; i < items.length; i++) {
    v = items[i] && (items[i].value != null ? items[i].value : items[i].agreed_value);
    if (String(v == null ? '' : v).trim() !== '') return true;
  }
  return false;
}

function consignList_(req, user) {
  var miss = consignMissing_(), today = consignToday_(), limit = consignOverdueDays_(), exec = isExec_(user), people = consignPeople_(), sheets = [];
  if (miss.length === 0) sheets = consignSheets_(today, limit, exec);
  var outPeople = people.map(function (p) {
    var o = { consignee_id: p.name, name: p.name, phone: p.phone };
    if (exec) { o.sold = 0; o.owed = 0; o.paid = 0; o.balance = 0; }
    return o;
  });
  var res = {
    ok: true, setup: miss.length === 0, missing: miss, overdue_days: limit, today: today, prices: exec,
    consignees: outPeople, sheets: sheets, loose: miss.length ? [] : consignLoose_(sheets)
  };
  if (exec) {
    var roll = { sold: 0, owed: 0, paid: 0, balance: 0 }, i, slot;
    sheets.forEach(function (s) {
      roll.sold += s.sold || 0;
      roll.owed = consignRound_(roll.owed + (s.owed || 0));
      roll.paid = consignRound_(roll.paid + (s.paid || 0));
      roll.balance = consignRound_(roll.balance + (s.balance || 0));
      slot = null;
      for (i = 0; i < outPeople.length; i++) if (consignSameName_(outPeople[i].name, s.consignee)) slot = outPeople[i];
      if (!slot) return;
      slot.sold += s.sold || 0;
      slot.owed = consignRound_(slot.owed + (s.owed || 0));
      slot.paid = consignRound_(slot.paid + (s.paid || 0));
      slot.balance = consignRound_(slot.balance + (s.balance || 0));
    });
    res.sold = roll.sold;
    res.sold_count = roll.sold;
    res.owed = roll.owed;
    res.paid = roll.paid;
    res.balance = roll.balance;
  }
  return res;
}
function consignSearch_(req, user) {
  var q = String(req.q || '').trim(), uq = q.toUpperCase().replace(/\s+/g, ' '), joQ = jobKey_(q);
  if (uq.length < 2 && !joQ) return { ok: true, q: q, hits: [] };
  var hits = [], seen = {};
  if (ss_().getSheetByName('JobOrders')) jobRows_('JobOrders').forEach(function (j) {
    if (jobStr_(j.status) === 'cancelled') return;
    var jo = jobKey_(j.jo), item = jobStr_(j.item_id), desc = jobStr_(j.description), loc = consignLoc_(j.location);
    if (!jo) return;
    var hay = (jo + ' ' + item + ' ' + desc).toUpperCase();
    if (!(joQ && jo.indexOf(joQ) >= 0) && hay.indexOf(uq) < 0 && (!item || item.toUpperCase().indexOf(uq) < 0)) return;
    consignPushHit_(hits, seen, { jo: jo, item_id: item, description: desc, location: loc });
  });
  if (ss_().getSheetByName('Items')) jobRows_('Items').forEach(function (r) {
    var item = jobStr_(consignCell_(r, ['item_id', 'sku', 'code'])), jo = jobKey_(consignCell_(r, ['jo', 'job', 'jo_number'])), desc = jobStr_(consignCell_(r, ['description', 'name', 'title'])), loc = consignLoc_(consignCell_(r, ['location']));
    if (!item && !jo) return;
    var hay = (jo + ' ' + item + ' ' + desc).toUpperCase();
    if (!(joQ && jo && jo.indexOf(joQ) >= 0) && hay.indexOf(uq) < 0) return;
    consignPushHit_(hits, seen, { jo: jo, item_id: item, description: desc, location: loc });
  });
  hits.forEach(function (h) { h.blocked = consignBlockReason_(h.jo, h.item_id, h.location); });
  hits.sort(function (a, b) { return consignCmp_(a.jo || a.item_id, b.jo || b.item_id); });
  return { ok: true, q: q, hits: hits.slice(0, 30) };
}

function consignSave_(req, user) {

  if (due && !/^\d{4}-\d{2}-\d{2}$/.test(due)) return { ok: false, error: 'Due date must look like 2026-11-19' };
  if (!due) due = consignAddDays_(today, limit);

function consignItem_(req, user) {
  var miss = consignMissing_(), bad = consignHeadersOk_();
  if (miss.length) return { ok: false, error: 'Run setupConsignment first' };
  if (bad) return { ok: false, error: bad };
  var status = String(req.status || '').toLowerCase();
  if (status !== 'returned' && status !== 'sold') return { ok: false, error: 'Status must be returned or sold' };
  var row = null, lineId = jobStr_(req.line_id || req.ci_id);
  if (lineId) row = consignFind_(['ci_id', 'line_id', 'id'], lineId);
  else row = consignMatchCode_(jobStr_(req.code), jobStr_(req.consignment_id));
  if (row && row.error) return row;
  if (!row) return { ok: false, error: lineId ? 'No such line' : 'No matching piece is still out' };

  var t = now_(), by = user.username, jo = jobKey_(consignCell_(row, ['jo'])), cid = jobStr_(consignCell_(row, ['consignment_id']));
  var before = consignSheetSettled_(cid);
  var changes = { status: status, updated_at: t, updated_by: by }, owed = null;
  if (status === 'returned') changes.returned_at = t;
  else {
    changes.sold_at = t;
    owed = consignOwedOf_(row);
  }
  consignUpdate_(row._row, changes);
  var locNote = '';
  if (jo && !consignOthersOut_(jo, lineId)) {
    var back = status === 'sold' ? 'sold' : (consignLoc_(consignCell_(row, ['prev_location', 'previous_location'])) || 'vault');
    if (back === 'consigned') back = 'vault';
    var job = consignJob_(jo);
    if (job) { consignSetLoc_(job, back, user, t); locNote = jo + ' -> ' + back; }
  } else if (jo) locNote = jo + ' still has another piece out';
  if (!before && consignSheetSettled_(cid)) audit_(by, 'consignClose', cid, '', 'every piece is returned or sold and paid');
  audit_(by, status === 'sold' ? 'consignSold' : 'consignReturn', lineId, req.device_id, cid + (status === 'sold' ? ' · owed ' + (owed == null ? 'blank' : owed) : '') + (locNote ? ' · ' + locNote : ''));

}
function consignPay_(req, user) {
  var miss = consignMissing_(), bad = consignHeadersOk_();
  if (miss.length) return { ok: false, error: 'Run setupConsignment first' };
  if (bad) return { ok: false, error: bad };
  if (!consignHas_(['paid_amount']) || !consignHas_(['paid_at']) || !consignHas_(['payment_id'])) {
    return { ok: false, error: 'The Consignment tab needs paid_amount, paid_at, and payment_id. setupConsignment does not change a tab that already exists.' };
  }
  var amount;
  try { amount = consignMoney_(req.amount); }
  catch (e) { return { ok: false, error: 'Type the amount paid' }; }
  if (amount === '' || !(amount > 0)) return { ok: false, error: 'Type the amount paid' };
  var date = jobStr_(req.date) || consignToday_();
  if (!/^\d{4}-\d{2}-\d{2}$/.test(date)) return { ok: false, error: 'Date must look like 2026-10-20' };
  var method = String(req.method || 'cash').toLowerCase();
  if ({ cash: 1, gcash: 1, bank: 1, other: 1 }[method] !== 1) method = 'other';
  var reference = consignClean_(req.reference, 80), note = consignClean_(req.note, 300);
  var lineId = jobStr_(req.line_id || req.ci_id), cid = jobStr_(req.consignment_id), lines = [], blank = false;
  if (lineId) {
    var row = consignFind_(['ci_id', 'line_id', 'id'], lineId);
    if (!row) return { ok: false, error: 'No such line' };
    if (consignNormStatus_(consignCell_(row, ['status'])) !== 'sold') return { ok: false, error: 'Record a payment on a sold piece' };
    if (consignOwedOf_(row) == null) return { ok: false, error: 'This sold piece has no agreed value, so there is no amount owed yet' };
    if (consignRemaining_(row) <= 0.009) return { ok: false, error: 'This piece is already paid' };
    lines = [row];
    cid = jobStr_(consignCell_(row, ['consignment_id']));
  } else if (cid) {
    consignRows_().forEach(function (r) {
      if (jobStr_(consignCell_(r, ['consignment_id'])) !== cid) return;
      if (consignNormStatus_(consignCell_(r, ['status'])) !== 'sold') return;
      if (consignOwedOf_(r) == null) { blank = true; return; }
      if (consignRemaining_(r) > 0.009) lines.push(r);
    });
    lines.sort(function (a, b) {
      return consignCmp_(consignDay_(consignCell_(a, ['date_out'])), consignDay_(consignCell_(b, ['date_out'])))
        || consignCmp_(consignLineId_(a), consignLineId_(b));
    });
    if (!lines.length) return { ok: false, error: blank ? 'A sold piece has no agreed value, so there is no amount to record yet' : 'Nothing sold on this sheet still has a balance' };
  } else return { ok: false, error: 'Pick a sold piece or a sheet' };
  var room = 0;
  lines.forEach(function (r) { room = consignRound_(room + consignRemaining_(r)); });
  if (amount > room + 0.5) return { ok: false, error: 'That is more than the balance' };
  if (amount > room) amount = room;
  var before = consignSheetSettled_(cid);
  var left = amount, t = now_(), by = user.username, payId = 'cp-' + randHex_(8), applied = [], payer = '';
  lines.forEach(function (r) {
    if (left <= 0.009) return;
    var rem = consignRemaining_(r);
    if (rem <= 0.009) return;
    var take = consignRound_(Math.min(left, rem));
    if (take <= 0) return;
    var prev = consignPaidOf_(r), next = consignRound_(prev + take);
    var lid = consignLineId_(r);
    var scid = jobStr_(consignCell_(r, ['consignment_id']));
    var who = consignPayer_(r);
    if (!payer) payer = who;
    var bal = Math.max(0, consignRound_((consignOwedOf_(r) || 0) - next));
    consignUpdate_(r._row, { paid_amount: next, paid_at: date, payment_id: payId, updated_at: t, updated_by: by });
    r.paid_amount = next;
    audit_(by, 'consignPay', lid, req.device_id, 'confirmed · payer ' + who + ' · ref ' + scid + ' ' + lid + ' · pay ' + payId + ' · ' + take + ' ' + method + (reference ? ' · receipt ' + reference : '') + (note ? ' · ' + note : '') + ' · paid ' + next + ' · balance ' + bal);
    applied.push({ line_id: lid, ci_id: lid, consignment_id: scid, amount: take, paid: next, balance: bal, payment_id: payId });
    left = consignRound_(left - take);
  });
  if (!applied.length) return { ok: false, error: 'Nothing to apply' };
  if (!before && consignSheetSettled_(cid)) audit_(by, 'consignClose', cid, '', 'every piece is returned or sold and paid');

}

function consignSheetView_(rows, today, limit, exec) {
  var name = '', phone = '', notes = '', dateOut = '', due = '', cid = '', copy = '';
  rows.forEach(function (r) {
    if (!cid) cid = jobStr_(consignCell_(r, ['consignment_id']));
    if (!name) name = jobStr_(consignCell_(r, ['consignee_name', 'consignee']));
    if (!phone) phone = jobStr_(consignCell_(r, ['consignee_phone', 'phone', 'mobile']));
    if (!notes) notes = jobStr_(consignCell_(r, ['notes']));
    if (!dateOut) dateOut = consignDay_(consignCell_(r, ['date_out', 'date']));
    if (!due) due = consignDay_(consignCell_(r, ['due_back', 'due_date', 'due']));
    var u = jobStr_(consignCell_(r, ['signed_copy_url']));
    if (u) copy = u;
  });
  var roll = { sold: 0, owed: 0, paid: 0, balance: 0 };
  var viewItems = rows.map(function (r) {
    var st = consignNormStatus_(consignCell_(r, ['status']));
    var dout = consignDay_(consignCell_(r, ['date_out'])) || dateOut;
    var idue = consignDay_(consignCell_(r, ['due_back', 'due_date', 'due'])) || due;
    var open = st === 'consigned';
    var money = consignViewMoney_(r);
    var lid = consignLineId_(r);
    var o = {
      line_id: lid, ci_id: lid, item_id: jobStr_(consignCell_(r, ['item_id', 'sku', 'code'])),
      jo: jobKey_(consignCell_(r, ['jo'])) || jobStr_(consignCell_(r, ['jo'])), description: jobStr_(consignCell_(r, ['description', 'name'])),
      status: st, date_out: dout, due_date: idue, prev_location: consignLoc_(consignCell_(r, ['prev_location', 'previous_location'])),
      returned_at: jobStr_(consignCell_(r, ['returned_at'])), sold_at: jobStr_(consignCell_(r, ['sold_at'])),
      days_out: consignSpan_(dout, today), overdue: open && consignIsOverdue_(dout, idue, today, limit), _settled: money.settled
    };
    var val = consignCell_(r, ['agreed_value', 'value']);
    if (val !== '' && val != null) o.value = consignMoneySafe_(val);
    if (exec && st === 'sold') {
      o.owed = money.owed;
      o.paid = money.paid;
      o.balance = money.balance;
      if (money.paid_at) o.paid_at = money.paid_at;
      if (jobStr_(consignCell_(r, ['payment_id']))) o.payment_id = jobStr_(consignCell_(r, ['payment_id']));
      roll.sold++;
      if (money.owed != null) {
        roll.owed = consignRound_(roll.owed + money.owed);
        roll.balance = consignRound_(roll.balance + (money.balance || 0));
      }
      roll.paid = consignRound_(roll.paid + money.paid);
    }
    return o;
  });
  var settled = viewItems.length > 0 && viewItems.every(function (it) { return it._settled; });
  viewItems.forEach(function (it) { delete it._settled; });
  var anyOpen = viewItems.some(function (it) { return it.status === 'consigned'; });
  var view = {
    consignment_id: cid, consignee: name, phone: phone, notes: notes,
    date_out: dateOut, due_date: due, status: settled ? 'closed' : 'open',
    days_out: consignSpan_(dateOut, today), overdue: anyOpen && viewItems.some(function (it) { return it.overdue; }), items: viewItems
  };

  if (copy) {
    view.signed_copy_url = copy;
    var thumb = consignThumb_(copy);
    if (thumb) view.signed_thumb = thumb;
  }
  return view;
}

function consignSignedFile_(req) {
  var b64 = String(req.file_base64 || '').replace(/\s/g, '');
  var comma = b64.indexOf(',');
  if (comma >= 0 && b64.slice(0, comma).indexOf('base64') >= 0) b64 = b64.slice(comma + 1);
  if (!b64) return { ok: false, error: 'Choose a photo or a PDF of the signed sheet' };
  if (b64.length > 12000000) return { ok: false, error: 'That file is too large. Use a photo or a PDF under 8 MB.' };
  var mime = String(req.mime || '').toLowerCase().split(';')[0].trim();
  if (mime === 'image/jpg') mime = 'image/jpeg';
  if (mime === 'image/svg+xml' || mime === 'image/svg') return { ok: false, error: 'Use a photo or a PDF' };
  if (mime !== 'application/pdf' && mime.indexOf('image/') !== 0) return { ok: false, error: 'Use a photo or a PDF' };
  var bytes;
  try { bytes = Utilities.base64Decode(b64); }
  catch (e) { return { ok: false, error: 'That file could not be read' }; }
  if (!bytes || !bytes.length) return { ok: false, error: 'That file is empty' };
  if (bytes.length > 8 * 1024 * 1024) return { ok: false, error: 'That file is too large. Use a photo or a PDF under 8 MB.' };
  return { bytes: bytes, mime: mime, name: consignFileName_(mime, jobStr_(req.consignment_id)) };
}
function consignFileName_(mime, cid) {
  var ext = 'img';
  if (mime === 'application/pdf') ext = 'pdf';
  else if (mime === 'image/jpeg') ext = 'jpg';
  else if (mime === 'image/png') ext = 'png';
  else if (mime === 'image/webp') ext = 'webp';
  else if (mime === 'image/gif') ext = 'gif';
  else if (mime === 'image/heic' || mime === 'image/heif') ext = 'heic';
  else ext = mime.slice(6).replace(/[^a-z0-9]/g, '').slice(0, 8) || 'img';
  var stamp = String(now_() || '').replace(/[^0-9]/g, '').slice(0, 14);
  return cid + '-signed-' + (stamp || 'file') + '-' + randHex_(4) + '.' + ext;
}

function consignThumbOf_(file) {
  if (!file || typeof file.getThumbnail !== 'function') return '';
  try {
    var blob = file.getThumbnail();
    if (!blob && typeof file.getBlob === 'function' && String(file.getMimeType() || '').indexOf('image/') === 0 && file.getSize() > 0 && file.getSize() <= 300000) blob = file.getBlob();
    if (!blob || typeof blob.getBytes !== 'function') return '';
    var bytes = blob.getBytes();
    if (!bytes || !bytes.length || bytes.length > 200000) return '';
    var ct = String((blob.getContentType && blob.getContentType()) || 'image/jpeg');
    if (ct.indexOf('image/') !== 0) return '';
    return 'data:' + ct + ';base64,' + Utilities.base64Encode(bytes);
  } catch (e2) { return ''; }
}
